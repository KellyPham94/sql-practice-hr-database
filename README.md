# 📊 SQL Practice - HR Database

This repository tracks my journey in mastering **Modern SQL** (from Basic to Advanced concepts) using the standard **HR Database**.

---

## 🛠️ Tech Stack & Key Concepts Covered
- **ANSI SQL Standards**: `INNER JOIN`, `LEFT JOIN`, `CROSS JOIN`.
- **Aggregation & Filtering**: `GROUP BY`, `HAVING`, `CASE WHEN`.
- **Advanced Querying**: Common Table Expressions (`WITH` CTE), Subqueries.
- **Window Functions**: `OVER()`, `PARTITION BY`, `DENSE_RANK()`, `SUM() OVER()`.
